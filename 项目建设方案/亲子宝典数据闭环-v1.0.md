## 3. monthlyFeedback 分桶策略

### 3.1 分桶粒度

**6 月分桶**（推荐）：
| 桶 ID | 月龄范围 | 典型对应 |
|---|---|---|
| 0-6m | 0-6 月 | 婴儿 |
| 7-12m | 7-12 月 | 婴儿 |
| 13-24m | 1-2 岁 | 幼儿 |
| 25-36m | 2-3 岁 | 幼儿 |
| 37-60m | 3-5 岁 | 学龄前（主力）|
| 61-84m | 5-7 岁 | 学龄前（主力）|
| 85-120m | 7-10 岁 | 学龄 |
| 121m+ | 10+ 岁 | 青少年 |

**理由**：覆盖童慧行主力 2-7 岁段，且每桶都有显著生理/心理差异。

### 3.3 聚合 SQL（伪）

```sql
-- 按月龄桶 + spotType 聚合
SELECT 
  bucketOf(age_at_visit) AS age_bucket,
  s.spot_type,
  AVG(avg_score) AS avg_score,
  COUNT(*) AS count
FROM child_ratings r
JOIN spots s ON s.id = r.spot_id
WHERE r.child_id = $1
GROUP BY age_bucket, s.spot_type;
```

## 4. crossSpotPattern 算法

### 4.1 目标

**计算"孩子从 spotA 到 spotB 的转移疲劳/兴奋度变化"**——例如：
- 动物园→科技馆：转移疲劳 0.3（基本无影响，可串联）
- 动物园→主题公园：转移疲劳 0.7（动物园耗精力，主题公园效果打折）

### 4.2 算法

**时间窗配对法**（推荐）：

```typescript
for each rating r at spot A (recordedAt=t1):
  find ratings r' at spot B with recordedAt in [t1, t1+4h]
  if found:
    delta = r'.emotionalPeak_score - r.emotionalPeak_score
    record: pattern[{from:A, to:B}].deltaDrops += delta
```

**关键点**：
- 时间窗：4 小时（典型上午/下午行程）
- 必须同一 plan（跨 plan 无意义）
- 至少 3 个样本才有意义

### 4.3 数据结构

```typescript
crossSpotPattern: {
  '动物园→科技馆': { 
    avgDrop: -0.3,           // 平均下降 0.3（轻微疲劳）
    sampleCount: 5, 
    confidence: 'medium'      // low/medium/high 基于样本数
  },
  '动物园→主题公园': { 
    avgDrop: -1.2,           // 显著下降
    sampleCount: 8,
    confidence: 'high'
  }
}
```

### 4.4 应用场景

- **assembler**：编排多 spot 时按 transfer fatigue 排序（A→B→C 选疲劳最低的路径）
- **/places/recommend**：返回"上午推荐 spot X，下午推荐 spot Y（与 X 兼容）"
- **UI**：plan 详情页显示"建议：动物园 + 科技馆组合（与动物园兼容 87% 同月龄孩子）"

### 6.2 monthlyFeedback 算法

```typescript
function computeMonthlyFeedback(childId: string) {
  const buckets = bucketByAgeOfRatings(allRatings);  // { '37-60m': [...], ... }
  const result = {};
  for (const [age, ratings] of Object.entries(buckets)) {
    const bySpotType = groupBy(ratings, r => r.spot.spotType);
    for (const [spotType, group] of Object.entries(bySpotType)) {
      const scores = group.map(r => emotionToScore(r.emotionalPeak)); // 兴奋=5, 平静=4, ...
      result[age] = result[age] || {};
      result[age][spotType] = {
        avgScore: avg(scores),
        count: group.length,
        topEmotion: mode(group.map(r => r.emotionalPeak))
      };
    }
  }
  return result;
}
```

### 6.3 crossSpotPattern 算法

```typescript
function computeCrossSpotPattern(childId: string) {
  // 按 planRecordId 分组
  const byPlan = groupBy(allRatings, r => r.planRecordId);
  const patterns = {};
  
  for (const [planId, ratings] of Object.entries(byPlan)) {
    const sorted = ratings.sort((a, b) => a.recordedAt - b.recordedAt);
    // 时间窗配对
    for (let i = 0; i < sorted.length; i++) {
      for (let j = i + 1; j < sorted.length; j++) {
        const gap = sorted[j].recordedAt - sorted[i].recordedAt;
        if (gap > 4 * 3600 * 1000) break;  // 超过 4 小时
        const fromSpot = sorted[i].spot;
        const toSpot = sorted[j].spot;
        const key = `${fromSpot.name}→${toSpot.name}`;
        const delta = emotionScore(sorted[j].emotionalPeak) - emotionScore(sorted[i].emotionalPeak);
        patterns[key] = patterns[key] || { drops: [], sampleCount: 0 };
        patterns[key].drops.push(delta);
        patterns[key].sampleCount++;
      }
    }
  }
  
  // 计算 avgDrop + confidence
  for (const key in patterns) {
    const drops = patterns[key].drops;
    patterns[key].avgDrop = avg(drops);
    patterns[key].confidence = drops.length >= 8 ? 'high' : drops.length >= 3 ? 'medium' : 'low';
  }
  
  return patterns;
}
```

### 8.2 算法

```typescript
async function recommend(req) {
  const { cityId, childId, tripContext } = req;
  const child = await getChildProfile(childId);
  const profile = await getChildFeelingProfile(childId);
  
  // 1. 拉同城市所有 spots
  const allSpots = await prisma.spot.findMany({ where: { cityId } });
  
  // 2. 过滤（用 child profile）
  const filtered = filterSpotsByChildProfile(allSpots, child);
  
  // 3. 排除已去过
  const remaining = filtered.filter(s => !tripContext.excludeSpotIds.includes(s.id));
  
  // 4. 评分 + 推荐理由
  const ranked = remaining.map(spot => {
    const reasons = [];
    let score = spot.kidScore ?? 0;
    
    // likes 加权
    if (child.likes?.some(l => spot.tags.includes(l))) {
      score *= 1.5;
      reasons.push({ type: 'likes', text: `你孩子喜欢「${matchedLike}」`, weight: 1.5 });
    }
    
    // 同月龄同 spotType 真实评分
    const ageBucket = bucketOf(child.ageMonths);
    const monthAvg = profile?.monthlyFeedback?.[ageBucket]?.[spot.spotType]?.avgScore;
    if (monthAvg && monthAvg >= 4) {
      reasons.push({ type: 'top_among_age', text: `${ageBucket} 同月龄孩子评 ${monthAvg}/5`, weight: 1.3 });
      score = 0.6 * score + 0.4 * monthAvg;
    }
    
    // 哭闹历史反向
    const cryTriggers = profile?.cryingTriggers ?? {};
    if (cryTriggers['crowded'] > 2 && spot.crowdLevel === 'low') {
      reasons.push({ type: 'no_cry_history', text: `你孩子易受人多影响，这里人少`, weight: 1.2 });
      score += 0.5;
    }
    
    return { spot, score, reasons };
  });
  
  // 5. 排序
  ranked.sort((a, b) => b.score - a.score);
  return ranked;
}
```
