## 二、v2 启动条件（任一触发）

以下任一行为出现，即视为走天下 v2 启动：

1. ❌ 创建 agency 数据库表（`prisma/schema.prisma` 含 `model Agency`）
2. ❌ 引入 bookingUrl / reservationId / createOrder 字段
3. ❌ 接入支付宝/微信支付/银联
4. ❌ 商家自助入驻后台（admin.grandand.com/agency）上线
5. ❌ 平台收取商家佣金 / 广告费 / 入驻费

## 三、v2 启动前必须完成的合规事项

### 3.1 证照办理

| 证照 | 主管部门 | 前置条件 | 预计时长 |
|---|---|---|---|
| **旅行社业务经营许可证** | 福建省文化和旅游厅 | 注册资本 ≥30 万 + 质量保证金 ≥20 万 + 3 名导游资格证 | 30-60 工作日 |
| **EDI 许可证**（增值电信业务经营许可证）| 福建省通信管理局 | 已完成 ICP 非经营性备案 + 注册资本 ≥100 万 + 3 名员工社保 | 60-90 工作日 |
| **道路运输许可证**（如涉及包车）| 交通运输局 | 车辆运营资质 + 司机从业资格证 | 30-45 工作日 |

### 3.2 注册资本补足

- **当前**：待用户确认（用户已知当前营业执照不含教育和旅游，预计注册资本也偏小）
- **目标**：补足至 ≥100 万（满足 EDI 要求）
- **路径**：股东增资 / 引入新股东 / 公积金转增

### 3.3 商家入驻资质审核 SOP

待 v2 启动时落地，需包含：

| 字段 | 核验方式 | 核验主体 |
|---|---|---|
| 营业执照 | 国家企业信用信息公示系统 | 平台 |
| 旅行社业务经营许可证 | 全国旅游监管服务平台 | 平台 |
| 导游人员资格证 | 文旅部查询系统 | 平台 |
| 道路运输许可证（包车类）| 交通运输局查询 | 平台 |
| 法人身份证 | 实名验证 | 平台 |
| 保证金（旅行社 ≥20 万）| 银行保函 / 资金托管 | 平台 + 银行 |

### 3.4 行程交易资金第三方托管

- 资金流不经过平台账户
- 第三方支付机构：支付宝商家 / 微信支付服务商
- 退款机制：T+1 自动原路退回
- 纠纷处理：7×24 客服 + 保险兜底

### 3.5 法律文书

- 《商家入驻协议》（含责权利、违约责任、解约条件）
- 《平台服务协议 v2.0》（用户侧，告知交易由第三方托管）
- 《隐私政策 v2.0》（扩展到商家主体）

## 五、CI 守护机制（v1 阶段已部署）

为防止 v1 阶段误引入 v2 触发字段，已在 `apps/travel-guide` 添加 ESLint 规则：

```yaml
# apps/travel-guide/.eslintrc.yml
rules:
  no-restricted-syntax:
    - error
    - selector: "Property[key.name='bookingUrl']"
      message: "走天下 v1 禁止 bookingUrl 字段，v2 agency 上线后开放"
    - selector: "Property[key.name='reservationId']"
      message: "走天下 v1 禁止 reservationId 字段"
    - selector: "CallExpression[callee.name=/alipay|wxpay|unionpay/i]"
      message: "走天下 v1 禁止接入支付接口"
```

**触发 v2 路径**：移除上述 lint 规则 + 完成第四节 9 项审查清单 + 办理两项前置证照。
