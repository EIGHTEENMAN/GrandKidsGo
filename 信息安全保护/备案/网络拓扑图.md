## 拓扑图需要展示的内容

公安联网备案要求提交网络拓扑图，说明数据流向、网络架构、关键节点。建议包含：

### 1. 公网入口层

```
用户（浏览器/H5/小程序）
  ↓
阿里云 CDN（华东 1 / 华北 2）
  ↓
WAF（Web 应用防火墙，可选）
  ↓
阿里云 SLB（负载均衡，可选）
  ↓
阿里云 ECS 47.114.77.124（杭州）:443/:80
```

### 2. 边缘层（nginx 反向代理）

```
nginx 443 端口
  ├─ grandand.com / www.grandand.com → main-site:3000
  ├─ xueshici.grandand.com → xueshici:3008
  ├─ xueguoxue.grandand.com → xueguoxue:3003
  ├─ xuetongshi.grandand.com → xuetongshi:3004
  ├─ english.grandand.com → english:3002
  ├─ tiaozhan.grandand.com → xiaodada:3011
  ├─ travel.grandand.com → travel-guide:3010
  ├─ m.grandand.com → mobile H5 (nginx 静态)
  └─ forum / store / auth / admin（暂不绑域名）
```

### 3. 应用层（13 个 app 进程）

```
main-site (Vue 3, port 3000)
xiaodada / tiaozhan (Vite + Express, port 3011 / backend 3001)
travel-guide (Next.js, port 3010)
xueshici / xueguoxue / xuetongshi / english (Vite, port 3008/3003/3004/3002)
mobile (uni-app H5, nginx 静态)
forum (Express, port 3005, 当前 pm2 stop)
store (Express, port 3006, 当前 pm2 stop)
auth-service (Express, port 3007)
admin (Ant Design, port 3099)
moderation (Express, port 3020, 当前 down)
```

### 4. 数据层

```
SQLite (auth-service 数据)
  ├─ users / children / parent_consent / youth_mode_settings / daily_usage
  ├─ 位置：阿里云 ECS 本地 /home/auth-service/data/
  └─ 备份：每日凌晨 3 点全量备份到 OSS（华北 2）

PostgreSQL (走天下 + 学习应用)
  ├─ cities / spots / plans / itineraries / badges / user_badges
  ├─ learning_progress / study_logs / poems / words
  ├─ 位置：阿里云 RDS（华东 1，杭州）
  └─ 备份：阿里云 RDS 自动备份 + 每日 OSS 异地备份
```

### 5. 第三方服务

```
阿里云 OSS：图片/头像/备份（境内）
阿里云通信：短信验证码（境内）
高德地图：POI 数据采集 API（境内）
微信开放平台：OAuth 登录（境内）
微软 Edge TTS：语音合成（境外，仅文本）
```

## 绘制建议

工具推荐（任选其一）：
- **draw.io**（开源，免费，本地或 web）
- **ProcessOn**（中文友好，免费版够用）
- **Figma**（专业，免费版够用）
- **Excalidraw**（手绘风格，免费）

模板建议：从阿里云官方 ECS 部署模板出发，叠加反向代理、应用进程、数据库节点。
